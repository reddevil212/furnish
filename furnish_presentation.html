Agentic AI Deep-Dive
8 Autonomous Tools Exposed to Gemini AI
🔍 Catalog & Specs Tools
  • search_products: Filters active inventory using word tokens, stems, and price ranges.
  • get_product_details: Retrieves full specifications, exact stock, and image URLs.
  • get_store_categories: Lists store categories with item counts for layout ideas.
🛒 Cart & Order Action Tools
  • get_user_cart: Calculates current user's itemized cart list and subtotal.
  • add_product_to_cart: Checks stock availability and inserts item into user cart.
  • remove_product_from_cart: Deletes items from current active cart session.
  • get_order_history & track_specific_order: Retrieves past order statuses via UUID.
Resilience & Security
Thread Safety & Local Fallback Engine
🔒 Thread-Safe ContextVar Isolation
  • Google GenAI SDK deep-copies function declarations during tool registration.
  • Furnish utilizes Python contextvars.ContextVar('active_agent') to bind the current web HTTP request context.
  • Guarantees that global tool functions operate strictly on the authenticated request user.
  • Prevents state leaking between concurrent users.
🛡️ Local Concierge Fallback Engine
  • Automatically engages if API key is missing or quota limits are exceeded (HTTP 429).
  • Performs token-matching regex catalog search directly against Django ORM.
  • Supports complete cart management and order tracking locally.
  • Ensures 100% continuous application availability regardless of external AI service status.
E-Commerce Flow
Checkout Flow & Razorpay Payments
💳 End-to-End Payment Processing Lifecycle
  • 1. Order Creation: User selects address and initiates order; backend calculates total and creates Razorpay Order ID (in paise).
  • 2. Client Checkout Modal: Frontend opens secure Razorpay JavaScript checkout modal with order details.
  • 3. Signature Verification: Payment response triggers payment_callback view; validates HMAC SHA256 signature using Razorpay Secret.
  • 4. Post-Payment Actions: Order status marked as completed, transaction ID recorded, and user cart automatically flushed.

Production Quality
Security Hardening & Performance
🔒 Security Architecture
  • HMAC SHA256 payment signature validation.
  • Django CSRF tokens enforced across all POST forms.
  • Protected endpoints (cart, orders, address book) locked behind authentication guards.
  • Secrets isolated in .env file.
⚡ Performance Optimizations
  • Zero N+1 query overhead using select_related() and prefetch_related().
  • ORM Category aggregations with Count() annotations.
  • Whitenoise asset compression and static caching.
  • Paginated catalog views (9 items/page).
