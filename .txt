\section{Introduction and Objectives of the Project}

\vspace{0.10in}

{\fontsize{13.5}{19.5}\selectfont
\begin{spacing}{1.2}

\noindent
\textbf{2.1 Introduction \& Context}

\vspace{0.05in}

\noindent
The retail furniture industry has witnessed rapid digital transformation; however, online consumer engagement has traditionally been impeded by the inability to visualize spatial harmony and color coordination across multi-item purchases. Standard e-commerce portals present static grids of products with disconnected descriptions, leaving buyers uncertain whether selected sofas, center tables, and storage units will cohesively integrate into their living spaces.

\vspace{0.10in}

\noindent
\textbf{Furnish} resolves this friction by synthesizing an end-to-end digital retail storefront with an intelligent, conversational interior styling assistant. Constructed on the robust Django Model-View-Template (MVT) architecture, the portal delivers a responsive catalog, multidimensional price and category filtering, custom customer address books, persistent wishlists, and seamless Razorpay payment processing. Concurrently, an autonomous AI shopping agent guides the customer from product discovery to post-order tracking.

\vspace{0.4in}

\noindent
\textbf{2.2 Objectives of the Project}

\vspace{0.05in}

\noindent
The core objectives guiding the architectural design and implementation of Furnish include:

\vspace{0.08in}

\begin{itemize}
    \setlength{\itemsep}{4pt}
    \setlength{\parskip}{0pt}
    \item \textbf{Comprehensive E-Commerce Architecture:} To engineer a reliable, role-secured web platform utilizing Python and Django, enabling smooth catalog discovery, user authentication, customer profile management, and persistent cart management.
    \item \textbf{Autonomous Generative AI Interior Stylist:} To integrate Google Gemini LLM with autonomous tool/function-calling capability, allowing the AI to recommend room-coordinated aesthetics, search catalog stock, mutate cart contents, and track shipments in natural language.
    \item \textbf{Normalized Relational Data Modeling:} To construct a structured RDBMS schema enforcing referential integrity across users, categories, products, wishlists, shopping carts, addresses, and order items.
    \item \textbf{Secure Transaction Processing:} To integrate the Razorpay payment gateway API with cryptographic signature verification (HMAC-SHA256) alongside Cash-on-Delivery (COD) to guarantee financial security.
    \item \textbf{Real-Time Order Tracking \& Fulfilment:} To establish complete order transparency utilizing unique UUID order tokens, automated tracking numbers, and instant status updates for consumers.
\end{itemize}

\end{spacing}
}

\section{Project Category}

\vspace{0.10in}

{\fontsize{13.5}{19}\selectfont
\begin{spacing}{1.18}

\noindent
As per academic and software engineering classification paradigms, the project \textbf{Furnish} constitutes a multi-faceted application synthesizing four essential computer science domains:

\vspace{0.12in}

\noindent
\textbf{3.1 Relational Database Management Systems (RDBMS)}

\vspace{0.04in}

\noindent
The backbone of Furnish is structured upon a fully normalized relational database (PostgreSQL), accessed through Django's Object-Relational Mapper (ORM). The data architecture models multi-table relational entities \textbf{(\texttt{User}, \texttt{Ecomm\_Category}, \texttt{Ecom\_Product}, \texttt{Ecom\_Favourites}, \texttt{Ecom\_Cart}, \texttt{Ecom\_Adress}, \texttt{Ecom\_Order}, and \texttt{Ecom\_OrderItem})} . Referential integrity is enforced through strict primary/foreign key mappings, cascading rules, unique slug constraints, and transactional consistency for order placement and payment status logging.

\vspace{0.4in}

\noindent
\textbf{3.2 Object-Oriented Programming Systems (OOPS)}

\vspace{0.04in}

\noindent
The application is constructed upon Python 3 and Django, embodying strict OOP principles:
\begin{itemize}
    \setlength{\itemsep}{2pt}
    \setlength{\parskip}{0pt}
    \item \textbf{Encapsulation:} Model classes encapsulate business constraints, auto-slugification within \texttt{save()} overrides, and calculated attributes (e.g., \texttt{total\_price} via properties).
    \item \textbf{Inheritance \& Modularity:} Models subclass Django's \texttt{models.Model}, while modular views cleanly isolate authentication, cart mutations, checkout workflows, and AI services.
    \item \textbf{Abstraction:} The \texttt{FurnishAIAgent} class abstracts complex LLM prompt construction, context variable handling, and tool execution behind clean interface methods.
\end{itemize}

\vspace{0.4in}

\noindent
\textbf{3.3 Artificial Intelligence \& Intelligent Agent Systems}

\vspace{0.04in}

\noindent
Furnish advances beyond static rule-based chatbots by deploying an \textbf{Agentic AI Shopping Concierge} utilizing the Google Gemini LLM. Powered by autonomous function calling, the AI agent is equipped with native tools (\texttt{search\_products}, \texttt{get\_product\_details}, \texttt{add\_product\_to\_cart}, \texttt{get\_order\_history}, \texttt{track\_specific\_order}). The agent reasons over customer intent, executes live database queries, performs shopping cart modifications, and delivers interactive visual UI responses.

\vspace{0.4in}

\noindent
\textbf{3.4 Web Engineering, Multimedia \& Distributed Networking}

\vspace{0.04in}

\noindent
The platform adopts a multi-tier client-server architecture. Secure networking protocols (HTTPS, TLS) govern communications, including CSRF token verification, session protection, RESTful AJAX endpoints for asynchronous AI streaming, media storage pipelines for high-resolution furniture imagery, and external webhook integrations with Razorpay servers.

\end{spacing}
}

\section{Non-functional Requirements}

\vspace{0.08in}

{\fontsize{13}{18}\selectfont
\begin{spacing}{1.15}

\noindent
Non-functional requirements outline the quality metrics, operational benchmarks, and security constraints governing the execution of the \textbf{Furnish} platform:

\vspace{0.10in}

\noindent
\textbf{8.1 Performance \& Low-Latency Responsiveness}
\begin{itemize}
    \setlength{\itemsep}{1.5pt}
    \item \textbf{Page Load Latency:} Catalog and product detail pages render under 1.5 seconds on standard broadband connections through query optimization and cached static assets.
    \item \textbf{Asynchronous AI Execution:} The AI stylist leverages asynchronous AJAX endpoints with lightweight JSON payloads, streaming tool outputs within 1.0 to 2.5 seconds.
    \item \textbf{Database Query Efficiency:} Utilizes Django ORM \texttt{select\_related} and query filters to prevent $N+1$ query bottlenecks during catalog browsing.
\end{itemize}

\vspace{0.08in}

\noindent
\textbf{8.2 Security, Cryptography \& Data Integrity}
\begin{itemize}
    \setlength{\itemsep}{1.5pt}
    \item \textbf{Authentication Security:} Passwords hashed via PBKDF2 with SHA-256 salts; session cookies secured with \texttt{HttpOnly} and \texttt{SameSite} flags.
    \item \textbf{Financial Transaction Integrity:} Razorpay webhook and checkout handshakes strictly validated via HMAC-SHA256 signature verification preventing tamper attacks.
    \item \textbf{Injection \& Cross-Site Protection:} Django ORM parameterized queries completely neutralize SQL injection; automatic template escaping mitigates XSS attacks.
\end{itemize}

\vspace{0.08in}

\noindent
\textbf{8.3 Reliability, Fault Tolerance \& AI Fallback}
\begin{itemize}
    \setlength{\itemsep}{1.5pt}
    \item \textbf{System Uptime:} Target operational availability of 99.9\% under normal deployment workloads.
    \item \textbf{Graceful Degradation:} If Google GenAI API rate limits or network failures occur, the AI concierge falls back gracefully with polite notifications without crashing the web app.
    \item \textbf{Transactional Integrity:} Order creation and cart purging execute within atomic database transactions to eliminate partial or corrupted order states.
\end{itemize}

\vspace{0.08in}

\noindent
\textbf{8.4 Usability, Aesthetics \& Cross-Device Portability}
\begin{itemize}
    \setlength{\itemsep}{1.5pt}
    \item \textbf{Responsive Design:} Adaptive layout built with HTML5, CSS3, and Bootstrap 5 ensures seamless accessibility across smartphones, tablets, laptops, and wide desktop screens.
    \item \textbf{Intuitive UI Elements:} Real-time visual feedback, interactive AI product cards, and consistent color palettes (\texttt{bcetblue}) ensure an effortless user journey.
\end{itemize}

def products(request):
    products_qs = Ecom_Product.objects.filter(product_is_active=True)

    # 1. Search Query with Case-Insensitive Q Filtering
    q = request.GET.get('q', '').strip()
    if q:
        products_qs = products_qs.filter(
            Q(product_name__icontains=q) |
            Q(product_description__icontains=q) |
            Q(product_category__category_name__icontains=q)
        )

    # 2. Category Filter (supports multiple selected categories)
    selected_categories = [c for c in request.GET.getlist('category') if c]
    if selected_categories:
        products_qs = products_qs.filter(product_category__category_slug__in=selected_categories)

    # 3. Price Preset Filter
    price_range = request.GET.get('price_range', '').strip()
    if price_range == 'under_5000':
        products_qs = products_qs.filter(product_price__lt=5000)
    elif price_range == '5000_10000':
        products_qs = products_qs.filter(product_price__gte=5000, product_price__lte=10000)
    elif price_range == '10000_25000':
        products_qs = products_qs.filter(product_price__gte=10000, product_price__lte=25000)
    elif price_range == 'above_25000':
        products_qs = products_qs.filter(product_price__gt=25000)

    # 4. Custom Min/Max Price Filtering
    min_price = request.GET.get('min_price', '').strip()
    max_price = request.GET.get('max_price', '').strip()
    if min_price:
        try:
            products_qs = products_qs.filter(product_price__gte=float(min_price))
        except ValueError:
            pass
    if max_price:
        try:
            products_qs = products_qs.filter(product_price__lte=float(max_price))
        except ValueError:
            pass

    # Pagination: 9 products per catalog page
    paginator = Paginator(products_qs.order_by('-product_created_at'), 9)
    page_number = request.GET.get('page')
    page_obj = paginator.get_page(page_number)

    categories = Ecomm_Category.objects.annotate(product_count=Count('products'))
    return render(request, 'products.html', {
        'products': page_obj,
        'categories': categories,
        'q': q,
        'selected_categories': selected_categories,
        'price_range': price_range,
    })

def add_to_cart(request, pid):
    if not request.user.is_authenticated:
        messages.warning(request, "Please log in to add products to your cart.")
        return redirect('login')

    product = get_object_or_404(Ecom_Product, id=pid, product_is_active=True)

    if not created:
        if cart_item.quantity < product.product_quantity_in_stock:
            cart_item.quantity += 1
            cart_item.save()
            messages.success(request, f"Updated {product.product_name} quantity to {cart_item.quantity}.")
        else:

    else:
        cart_item.quantity = 1
        cart_item.save()
        messages.success(request, f"Added {product.product_name} to cart.")

    return redirect(request.META.get('HTTP_REFERER', 'cart'))


def update_cart_quantity(request, pid, action):
    if not request.user.is_authenticated:
        return redirect('login')

    cart_item = get_object_or_404(Ecom_Cart, user=request.user, product__id=pid)
    product = cart_item.product

    if action == 'plus':
        if cart_item.quantity < product.product_quantity_in_stock:
            cart_item.quantity += 1
            cart_item.save()
        else:
            messages.error(request, f"Maximum available stock reached ({product.product_quantity_in_stock}).")
    elif action == 'minus':
        if cart_item.quantity > 1:
            cart_item.quantity -= 1
            cart_item.save()
        else:
            cart_item.delete()

    return redirect('cart')

def order_process(request):
    if not request.user.is_authenticated:
        return redirect('login')

    if request.method == "POST":
        address_id = request.POST.get('address_id')
        payment_method = request.POST.get('payment_method')
        cart_items = Ecom_Cart.objects.filter(user=request.user).select_related('product')
        shipping_address = Ecom_Adress.objects.filter(id=address_id, user=request.user).first()
        total_amount = sum(item.total_price for item in cart_items)
        tracking_number = f"{uuid.uuid4().hex[:8].upper()}"

        if payment_method == 'online':
            order = Ecom_Order.objects.create(
                user=request.user, shipping_address=shipping_address,
                total_amount=total_amount, payment_mode='online',
                payment_status='pending', order_tracking_number=tracking_number
            )
            order_items = [Ecom_OrderItem(order=order, product=i.product, quantity=i.quantity) for i in cart_items]
            Ecom_OrderItem.objects.bulk_create(order_items)

            # Initialize Razorpay Client and create payment order
            client = razorpay.Client(auth=(settings.RAZORPAY_KEY_ID, settings.RAZORPAY_KEY_SECRET))
            razor_order = client.order.create({
                'amount': int(total_amount * 100), 'currency': 'INR', 'payment_capture': '1',
                'notes': {'order_id': str(order.order_id), 'user_id': str(request.user.id)}
            })
            order.razor_order_id = razor_order['id']
            order.save()
            return redirect('payment_page', order_id=order.order_id)


@csrf_exempt
def payment_callback(request):
    if request.method == "POST":
        razorpay_payment_id = request.POST.get('razorpay_payment_id')
        razorpay_order_id = request.POST.get('razorpay_order_id')
        razorpay_signature = request.POST.get('razorpay_signature')

        order = Ecom_Order.objects.filter(razor_order_id=razorpay_order_id).first()
        client = razorpay.Client(auth=(settings.RAZORPAY_KEY_ID, settings.RAZORPAY_KEY_SECRET))
        params_dict = {
            'razorpay_order_id': razorpay_order_id,
            'razorpay_payment_id': razorpay_payment_id,
            'razorpay_signature': razorpay_signature
        }

        try:
            # Cryptographic signature verification
            client.utility.verify_payment_signature(params_dict)
            order.payment_status = 'completed'
            order.razor_payment_id = razorpay_payment_id
            order.razorpay_signeture = razorpay_signature
            order.save()
            # Deduct inventory stock and clear active cart
            for item in order.item.all():
                item.product.product_quantity_in_stock -= item.quantity
                item.product.save()
            Ecom_Cart.objects.filter(user=order.user).delete()
            return redirect('orders')
        except razorpay.errors.SignatureVerificationError:
            order.payment_status = 'failed'
            order.save()
            return redirect('checkout')

def ai_chat_view(request):
    """
    Handles user chat interaction with Furnish Agentic AI.
    Executes tool calling (catalog search, cart updates, order tracking)
    and returns structured JSON with conversational text, rich product cards,
    and live cart metrics.
    """
    if request.method != "POST":
        return JsonResponse({"status": "error", "message": "Only POST method allowed."}, status=405)

    try:
        data = json.loads(request.body.decode('utf-8'))
    except Exception:
        data = request.POST

    user_message = data.get("message", "").strip()
    if not user_message:
        return JsonResponse({"status": "error", "message": "Message cannot be empty."}, status=400)

    # Retrieve multi-turn conversation history from user session
    session_history = request.session.get("furnish_ai_chat_history", [])

    # Instantiate AI Agent and execute autonomous reasoning cycle
    agent = FurnishAIAgent(request=request)
    result = agent.chat(user_message, session_history=session_history)

    # Persist updated session history
    request.session["furnish_ai_chat_history"] = result.get("history", [])
    request.session.modified = True

    return JsonResponse(result)

    return JsonResponse({"status": "error", "message": "POST required."}, status=405)

\section{System Security Measures}

\vspace{0.06in}

{\fontsize{12.5}{17}\selectfont
\begin{spacing}{1.12}

\noindent
To safeguard user data, payment transactions, and administrative resources, the system implements robust security layers:
\begin{itemize}
    \setlength{\itemsep}{1.5pt}
    \item \textbf{Authentication \& Password Encryption:} Passwords securely hashed using PBKDF2 with SHA-256 salts. Sessions enforced with \texttt{HttpOnly} and \texttt{SameSite=Lax} flags to prevent session hijacking.
    \item \textbf{CSRF Protection:} Every state-mutating form and AJAX POST payload mandates a unique, cryptographically signed CSRF token (\texttt{csrf\_token}).
    \item \textbf{Payment Verification Integrity:} Online payments require HMAC-SHA256 signature verification comparing Razorpay credentials against incoming callback tokens before updating order states.
    \item \textbf{XSS \& Injection Defense:} Django's automatic template escaping sanitizes user inputs, mitigating Cross-Site Scripting (XSS).
\end{itemize}

\end{spacing}
}

Database protection is paramount for ensuring transaction consistency and safeguarding personal consumer records:
